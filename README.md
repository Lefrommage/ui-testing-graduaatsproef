# UI-Testing Graduaatsproef: Selenium vs Playwright

Proof of concept voor de graduaatsproef *"Van Selenium naar Playwright: een praktische evaluatie van UI-testautomatisatie"*. Dit project vergelijkt twee tools voor UI-testautomatisatie, Selenium en Playwright, door dezelfde testscenario's met beide tools te implementeren en te evalueren.

De tests draaien tegen de demo-webapplicatie [SauceDemo](https://www.saucedemo.com/), die een realistische flow biedt: login, productoverzicht, winkelmand en checkout.
